AI meme game where a system judges your choices.

You pick:

- 🔴 Red
- 🔵 Blue

System responds with cold, sarcastic judgment.

No score. No win. Just evaluation.

## Stack

- FastAPI (backend)
- Godot 4.6.2 (game engine)
- Gemini API
- edge-tts
- JSON pool system
